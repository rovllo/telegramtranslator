# Telegram Translator

<div dir="rtl">

بات تلگرام برای ترجمه و آماده‌سازی پست‌های کانال با مدل Gemini.

هر پستی که برای بات بفرستید یا فوروارد کنید (متن، عکس، ویدیو، گیف، فایل، صوت یا آلبوم)، متنش به فارسی روان و درست ترجمه می‌شود، پاراگراف‌بندی حفظ می‌شود، امضا و لینک کانال مبدأ حذف می‌شود و قالب و امضای کانال شما اضافه می‌شود. پیش‌نمایش با دو دکمه برای ادمین ارسال می‌شود:

- **📢 انتشار**: ارسال پست به همه کانال‌ها و گروه‌های ثبت‌شده
- **🔄 ترجمه دوباره**: ساخت نسخه‌ای جدید از ترجمه

اگر روی پیش‌نمایش ریپلای کنید و توضیح بنویسید (مثلاً «لحن رسمی‌تر» یا «خط آخر حذف شود»)، ترجمه طبق همان توضیح دوباره ساخته می‌شود.

## امکانات

- پشتیبانی از متن، عکس، ویدیو، گیف، فایل، صوت، ویس و آلبوم
- حفظ ساختار پاراگراف‌ها، خطوط و ایموجی‌ها
- حذف امضا، آیدی و لینک تبلیغاتی کانال مبدأ
- قالب یکسان انتشار با امضای اختصاصی و تیتر پررنگ
- مدیریت محدودیت ۱۰۲۴ کاراکتری کپشن (ارسال متن جداگانه در صورت نیاز)
- ثبت خودکار کانال‌ها و گروه‌هایی که بات به آن‌ها اضافه می‌شود
- تلاش دوباره خودکار هنگام خطای محدودیت نرخ (429) یا خطای سرور
- فقط ادمین‌های تعریف‌شده به بات دسترسی دارند

## پیش‌نیازها

- Python 3.10 یا بالاتر
- توکن بات از [@BotFather](https://t.me/BotFather)
- کلید API از [Google AI Studio](https://aistudio.google.com/)
- سروری با دسترسی آزاد به تلگرام و Gemini API

## نصب

</div>

```bash
git clone https://github.com/rovllo/telegramtranslator.git /opt/translator-bot
cd /opt/translator-bot
python3 -m venv venv
venv/bin/pip install -r requirements.txt
cp .env.example .env
```

<div dir="rtl">

سپس فایل `.env` را پر کنید:

| متغیر | توضیح |
|---|---|
| `BOT_TOKEN` | توکن بات تلگرام |
| `GEMINI_API_KEY` | کلید API گوگل |
| `GEMINI_MODEL` | شناسه مدل (پیش‌فرض: `gemini-4-hydrogen`) |
| `THINKING_LEVEL` | سطح تفکر مدل: `low`، `medium`، `high` یا خالی |
| `ADMIN_IDS` | آیدی عددی ادمین‌ها، جداشده با کاما |
| `DATA_FILE` | مسیر فایل ذخیره‌سازی (پیش‌فرض: `data.json`) |

## اجرا

</div>

venv/bin/python bot.py

## افزودن مقصدهای انتشار

۱. در حالی که بات روشن است، آن را در کانال یا گروه ادمین کنید و دسترسی ارسال پیام بدهید. بات به‌صورت خودکار مقصد را ثبت و به شما اطلاع می‌دهد.

۲. برای کانال‌هایی که بات از قبل در آن‌ها عضو بوده، از دستور `/addchat` استفاده کنید؛ چون API تلگرام فهرست چت‌های بات را در اختیار نمی‌گذارد.

## دستورات

| دستور | کاربرد |
|---|---|
| `/start` | راهنما |
| `/chats` | فهرست مقصدهای انتشار |
| `/addchat @channel` | افزودن دستی کانال یا گروه (یوزرنیم یا آیدی عددی) |
| `/removechat -100…` | حذف مقصد |

## شخصی‌سازی

- **امضا و قالب:** متغیرهای `SIGNATURE`، `TEMPLATE` و `BOLD_FIRST_LINE` در `config.py`
- **قوانین ترجمه:** متن `SYSTEM_PROMPT` در `translator.py` (لحن، اعداد فارسی، موارد حذفی و…)

## ساختار پروژه

</div>

```text
bot.py                  # هندلرهای تلگرام، پیش‌نمایش، انتشار
translator.py           # ارتباط با Gemini و پرامپت ترجمه
storage.py              # ذخیره مقصدها و پست‌ها در JSON
config.py               # تنظیمات و قالب انتشار
translator-bot.service  # سرویس systemd
```

## نکات

- قالب‌بندی متن اصلی (bold، لینک‌های پنهان) در ترجمه حفظ نمی‌شود و فقط قالب تعریف‌شده اعمال می‌شود.
- پست‌های کانال‌هایی که «محتوای محافظت‌شده» دارند قابل فوروارد نیستند.
- در tier رایگان Gemini، سقف درخواست روزانه را در بخش Rate Limits حساب AI Studio بررسی کنید.
